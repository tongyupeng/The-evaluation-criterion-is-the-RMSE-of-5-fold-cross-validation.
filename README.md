# 🎬 MovieLens 20M 矩阵补全：凸优化 vs 非凸优化

## 📊 项目简介

本项目基于**MovieLens 20M数据集**（2000万条电影评分），系统对比了**凸优化方法（核范数正则化）**与**非凸优化方法（扩展矩阵分解）**在低秩矩阵补全任务上的性能差异。实验涵盖完整的数据分析、预处理、模型实现与交叉验证流程，为推荐系统研究提供可复现的基准对比。

## 🎯 核心对比

### ⚖️ 方法对比
| 维度 | 凸优化 (Soft-Impute) | 非凸优化 (Biased MF + ALS) |
|------|-------------------|--------------------------|
| **正则化方式** | 核范数正则化 | Frobenius范数 + 标签敏感度正则 |
| **秩控制** | 自动软阈值收缩 | 固定隐因子维度(k=20) |
| **时间建模** | 时间权重(预留) | 显式时间动态偏置(5年份桶) |
| **语义建模** | 无 | 可学习标签热度偏置 |
| **优化保证** | 全局最优收敛 | 局部最优，实用性能强 |

## 🔬 实验亮点

### 📁 模块化实现
1. **EDA与预处理** (`EDA.py`)
   - 评分分布分析与稀疏度计算(99.47%)
   - 连续ID映射与偏差中心化
   - 时间特征工程与标签热度构建

2. **凸优化模块** (`convex.py`)
   - 加权Soft-Impute算法实现
   - 线性算子优化，避免显式稠密矩阵
   - 部分SVD加速与自动秩选择

3. **非凸优化模块** (`nonconvex.py`)
   - 扩展偏置矩阵分解：`μ + b_u + b_i + b_{i,t} + p_u^T q_i + γ·标签偏置`
   - 交替最小二乘法(ALS)高效求解
   - 多层次偏置建模：静态、时间动态、语义标签

## ⚡ 工程优化

### 🚀 性能优化
- **内存管理**：稀疏存储 + LinearOperator + 主动垃圾回收
- **计算加速**：向量化einsum、CSR行列快速访问、预计算标签偏置表
- **收敛监控**：详细迭代日志 + 提前停止机制

### 🔧 代码质量
- 模块化设计，便于扩展
- 完整类型提示与文档字符串
- 鲁棒性处理：SVD退化回退、预测值裁剪、数值稳定性保证

## 📊 实验结果

### 评估指标
- 核心指标：**验证集RMSE** (5折交叉验证)
- 辅助监控：拟合损失、当前秩、训练时间、内存使用

### 超参数搜索
- 凸方法：λ ∈ [100, 50, 10]
- 非凸方法：λ ∈ [10.0, 1.0]，标签正则λ_s=1.0

## 📈 主要发现

1. **凸方法优势**：理论保证强，适合作为鲁棒性基线
2. **非凸方法优势**：通过多层次偏置建模，能更好地捕捉时间动态与语义信息
3. **实践建议**：推荐系统实际部署中，非凸方法通常能在合理计算成本下获得更优效果
